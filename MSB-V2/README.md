# MSB-V2 — Unired Business (мобильный банк для юрлиц)

Аналитика по Figma-файлу **MSB-V2 / Project**. Дата: 2026-06-25.

## Что это за продукт

**Unired Business** — мобильный корпоративный банк (супер-апп) для юридических лиц и ИП в Узбекистане. Покрывает регистрацию (ИП/ООО), онбординг, авторизацию, дашборд с документами на подпись, счета и выписки, платёжные поручения (в т.ч. бюджетные), контрагентов с задолженностью, зарплатные проекты, кадры, приём оплаты по QR, отчётность, статистику, коммунальные платежи, транспорт, центр поддержки, новости/уведомления и боковое меню (профиль/настройки). Дизайн — в статусе Work in progress.
