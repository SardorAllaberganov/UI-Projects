# MSB-V2 — Unired Business (мобильный банк для юрлиц)

Аналитика по Figma-файлу **MSB-V2 / Project**. Дата: 2026-06-22.

## Что это за продукт

**Unired Business** — мобильное приложение корпоративного банка (клиент-банк) для юридических лиц и ИП в Узбекистане. Покрывает онбординг, авторизацию, дашборд с документами на подпись, счета и выписки, платёжные поручения (в т.ч. бюджетные), контрагентов с задолженностью, зарплатные проекты, кадры, приём оплаты по QR и отчётность. Дизайн — в статусе Work in progress.
